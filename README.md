## 🏆 Featured — Podium Vote · SaaS Voting & Payments Platform

A production SaaS I **designed, built, and deployed from scratch**. It runs live voting and
ticketing for paying clients, moving real money through Stripe Connect.

- **Payments** — Stripe Connect with destination-charge splits routing funds to each client's
  own connected account, and idempotent webhooks for **exactly-once** vote crediting
  (**100+ live transactions**).
- **Scale & reliability** — **~65,000 votes** processed across two live events, with peaks of
  **~18,000 in a single day** and **zero downtime**; a Redis cache (5s TTL) absorbs
  live-leaderboard reads to shield the database.
- **Architecture** — database-per-tenant isolation, per-tenant branding, and role-based
  admin panels.
- **Production migration** — moved the entire platform from Azure to **AWS + Railway** in production.

**Stack:** FastAPI · Angular (standalone + signals) · SQL Server · Redis · AWS (RDS, Amplify, S3) · Railway · Cloudflare · Stripe Connect · Resend
